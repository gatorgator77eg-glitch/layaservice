Labelled Examples → Calibration

Use the Console to manage profiles, upload/replace examples, and fit/activate calibration. This page is a placeholder for future training workflows (dataset curation, sweeps, evaluations).

Quick Start

  1. Create a profile in Console (questions + routing)
  2. Add labelled examples (PUT /v1/profiles/{id}/examples)
  3. Fit calibration (POST /v1/profiles/{id}/calibration/fit)
  4. Activate (POST /v1/profiles/{id}/calibration/activate)
  5. Predict via minted endpoint /v1/profiles/{id}/predict
See doc.txt and doc_monitoring.txt for full API details.
